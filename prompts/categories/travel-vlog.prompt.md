# 旅行 vlog

## 简介

一段旅程里多个地方的混剪或碎片：交通、景点、住宿、吃喝、人物出镜，
常带口播和剪辑过的镜头切换。

## 看片重点

- 地点：每个画面在哪里，能确认的城市、景点、地标写进 landmark，
  认不出就留空。
- 旅程感：出发、在路上、到达、交通工具、行李、地图和路牌。
- 人物：出镜的人在做什么，表情和互动。
- 亮点：景点的标志性画面、夜景、特别的体验。
- 镜头质量：稳不稳、曝光是否正常、有没有被挡。

## 精彩度标准

- 5：这段旅程最值得记住的画面。标志性景点的好镜头、壮观的夜景或风景、
  人物最开心的瞬间。
- 4：有地点特色的好镜头。一看就知道在哪，主体清楚、画面稳定。
- 3：普通可用。交代了地点或过程，但不出彩，适合做过渡。
- 2：平淡或有瑕疵。看不出在哪、主体不清、晃动或过暗。
- 1：不可用。严重模糊、黑屏或被遮挡。

## 成片结构

开场最抓人的一个画面 → 出发与在路上 → 按地点依次展开，每地一两个
最好的镜头 → 最高潮的地点或体验 → 收尾（回望、夜景或离开）。

## 解说风格

轻快的第一人称旅行日记；每到一地一句话点出地名和印象；只说画面里能
确认的地点；结尾一句回味整段旅程。
